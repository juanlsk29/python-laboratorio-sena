# Python – Laboratorio 4

Este repositorio contiene los programas que desarrollé en mi cuarto laboratorio de Python.

En este laboratorio aprendí a hacer mis programas más seguros y duraderos. En la práctica 4-1 trabajé con excepciones: usé try, except, else y finally para que el programa no se cierre cuando el usuario escribe letras o intenta abrir un archivo que no existe. En la práctica 4-2 aprendí a leer y escribir archivos de texto, crear carpetas y generar reportes y bitácoras. En la práctica 4-3 trabajé con archivos JSON y CSV para guardar y cargar datos de productos, libros y ventas.

En la práctica 4-4 estudié la herencia, la sobrescritura de métodos, el polimorfismo y la composición entre clases, con ejemplos como vehículos, instructores y un sistema de notificaciones.

Todo lo anterior lo reuní en el proyecto final, la carpeta gestor_inventario. Es mi gestor de inventario de consola, ahora con persistencia: guarda los productos en un archivo JSON, los carga al iniciar y exporta un reporte en CSV. Además maneja los errores de lectura y escritura y usa rutas que funcionan sin importar desde qué carpeta se ejecute el programa. Mis notas sobre los problemas que encontré y cómo los resolví están en notas_depuracion.md.

Las pruebas que hice de cada programa quedaron como comentarios dentro de los archivos.

Para ejecutarlo necesitas tener Python 3 instalado. Primero clona el repositorio con git clone https://github.com/juanlsk29/python-laboratorio-sena.git y entra a la carpeta del proyecto desde la terminal. Luego entra a la carpeta de la práctica que quieras probar y ejecuta el archivo escribiendo python y su nombre, por ejemplo python division_segura.py dentro de practica-4-1. Para el proyecto final entra a la carpeta gestor_inventario y ejecuta python main.py. Si el programa pide datos, escríbelos y presiona Enter.

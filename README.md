# Python – Laboratorio 2

Este repositorio contiene los programas que desarrollé en mi segundo laboratorio de Python.

En este laboratorio practiqué las estructuras de control y las colecciones del lenguaje. Primero trabajé con condicionales y operadores de comparación para validar datos como la edad, las compras y el acceso a una sala. Después usé los ciclos for y while para crear contadores, tablas de multiplicar, promedios y menús que se repiten hasta que el usuario decide salir.

También aprendí a manejar listas, tuplas, conjuntos y diccionarios. Con ellos hice programas para guardar tareas, quitar duplicados, consultar catálogos de libros y productos, y calcular informes de inventario. Todo lo anterior lo reuní en el programa final, gestor_inventario.py, un menú que permite registrar, listar, buscar, actualizar y eliminar productos, además de consultar los que no tienen existencias y ver un resumen del inventario.

Las pruebas que hice de cada programa quedaron como comentarios al final de cada archivo.

Para ejecutarlo necesitas tener Python 3 instalado. Primero clona el repositorio con git clone https://github.com/juanlsk29/python-laboratorio-sena.git y entra a la carpeta del proyecto desde la terminal. Luego ejecuta cualquier programa escribiendo python y el nombre del archivo, por ejemplo python gestor_inventario.py. Si el programa pide datos, escríbelos y presiona Enter.

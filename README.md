# Python – Laboratorio 3

Este repositorio contiene los programas que desarrollé en mi tercer laboratorio de Python.

En este laboratorio aprendí a organizar mejor mi código. En la práctica 3-1 trabajé con funciones, parámetros, valores de retorno y alcance de variables. En la práctica 3-2 separé mi código en módulos para importarlo desde otros archivos, y con eso armé un cotizador modular y un conversor de unidades.

En la práctica 3-3 comencé con la programación orientada a objetos, creando clases como Estudiante y Billetera con sus atributos y métodos. En la práctica 3-4 profundicé en el encapsulamiento, las propiedades, el manejo de errores con try y except y la relación entre objetos, por ejemplo entre un inventario y sus productos.

Todo lo anterior lo reuní en el proyecto final, la carpeta gestor_inventario. Es una aplicación de consola donde cada producto es un objeto de la clase Producto y la clase Inventario se encarga de registrar, listar, buscar, actualizar y eliminar productos, consultar los que no tienen existencias, ver un resumen y ordenar o filtrar por categoría. Producto valida sus datos y main.py maneja la interacción con el usuario.

Las pruebas que hice de cada programa quedaron como comentarios dentro de los archivos.

Para ejecutarlo necesitas tener Python 3 instalado. Primero clona el repositorio con git clone https://github.com/juanlsk29/python-laboratorio-sena.git y entra a la carpeta del proyecto desde la terminal. Luego entra a la carpeta de la práctica que quieras probar y ejecuta el archivo escribiendo python y su nombre, por ejemplo python alcance.py dentro de practica-3-1. Para el proyecto final entra a la carpeta gestor_inventario y ejecuta python main.py. Si el programa pide datos, escríbelos y presiona Enter.
